## ✨ Design Notes

- **Zero frameworks, zero build step** — pure HTML/CSS/JS, deploys as static files
- Full-screen **video backgrounds** on key pages for a cinematic feel
- Project cards backed by real artifacts (screenshots, PDFs) in the repo

## 🚀 Run Locally

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
